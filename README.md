# Life's Good Without Spying

A webOS homebrew app that switches off the surveillance stack on rooted LG
TVs: ad delivery, Automatic Content Recognition, and always-on voice capture.

> [!NOTE]
> **AI Generated Software Ahead**  
> While this is a pretty simple app, and tested on my TV, most of the code was generated by AI.

> [!WARNING]
> This project has only been tested on **WebOS 23 (9)**. It may or may not work on WebOS 24 (10).

## Features

- Blackholes LG ad / ACR / telemetry domains to loopback by bind-mounting a
  generated `/etc/hosts` (per-category toggles).
- Stops the on-TV ad services (`admanager`, `adoverlay`, `livepick`).
- Stops the LG voice services (`voiceinput`, `voiceconductor`).
- Re-checks those kills every minute, since the TV respawns them.
- Wipes locally buffered ACR / speech-to-text files.
- Re-applies everything at boot through a Homebrew Channel `init.d` hook.

## Requirements

- A rooted LG webOS **(9)** TV with the Homebrew Channel installed.
- Tested on: OLED65G45LW (EU), webOS TV 9.2.4, firmware 23.23.30.

## Build

Needs `ares-package` ([setup](https://www.webosbrew.org/develop/guides/env-setup))
and `rsvg-convert` for the icons:

```
./build.sh
```

Builds an `.ipk` plus its sha256 into `dist/`.

## Install

With the TV reachable over SSH, either sideload it:

```
ares-install <device> dist/*.ipk
```

or push the `.ipk` to `/tmp` on the TV and install as root:

```
luna-send -i -f luna://com.webos.appInstallService/dev/install \
  '{"id":"ooo.lew.lifesgoodwithoutspying","ipkUrl":"/tmp/app.ipk","subscribe":true}'
```

(Uses `ssh -tt`: this TV's `luna-send` only prints on a TTY, and `-i`
subscribes forever, so wrap it in `timeout`.)

## Use

Open the app from the home screen. Enable whatever options you'd like, and choose 'Enable Protection',
and the main button cycles Enable / Update / Disable.


## Notes

- You don't need the update block option if you've got the option set in the Homebrew Channel.
