# Life's Good Without Spying

[![build](https://github.com/lewisdoesstuff/lifesgoodwithoutspying/actions/workflows/build.yml/badge.svg)](https://github.com/lewisdoesstuff/lifesgoodwithoutspying/actions/workflows/build.yml)

A webOS homebrew app that switches off the surveillance stack on rooted LG
TVs: ad delivery, Automatic Content Recognition, and always-on voice capture.

![The app's main screen on an LG G4 running webOS 9](assets/screenshot.png)

> [!NOTE]
> **AI Generated Software Ahead**  
> While this is a pretty simple app, and tested on my TV, most of the code was generated by AI.

> [!WARNING]
> Supported on **webOS 4 and newer**. It has been *tested* on **webOS 23 (9)**,
> **webOS 25**, and **webOS 4.4** so far, and users report that webOS 5 and
> newer work as well.

## What it does

- **Blocks LG ad, ACR, and telemetry domains** via a generated `/etc/hosts`
  with per-category toggles. Lines that other tools (like LG App Update
  Blocker) add to `/etc/hosts` are preserved.
- **Stops on-TV ad, ACR, telemetry, and voice services** and bind-mounts inert
  stubs over them so that webOS cannot restart them. A small stand-in answers
  basic Luna calls so that Settings and apps do not hang.
- **Wipes locally buffered ACR and speech-to-text files.**
- **Optionally filters local DNS** through a reversible IPv4 proxy for lookups
  that bypass `/etc/hosts` (with an optional IPv6 kill switch).
- **Re-applies automatically at boot** through a Homebrew Channel `init.d`
  hook, and cleanly restores services and settings when you disable protection.

## Requirements

- A rooted LG TV running **webOS 4 or newer** with the Homebrew Channel
  installed.
- **Tested on:** LG G4 (`OLED65G45LW`, webOS 9.2.4 / firmware 23.23.30), LG B5
  (`OLED65B5PUA`, webOS 25 / firmware 33.31.68), and webOS 4.4. Reported
  working on webOS 5+.
- **webOS 4.x note:** Some 4.x firmware never runs the Homebrew Channel startup
  hook ([webos-homebrew-channel#124](https://github.com/webosbrew/webos-homebrew-channel/issues/124)).
  If protection is off after a reboot, open the app and select **Update
  protection**.

## Install

Install **Life's Good Without Spying** from the Homebrew Channel.

## Use

Open the app from the home screen, choose the options you want, and select
**Enable Protection**. From there, the main button cycles between **Enable**,
**Update**, and **Disable**.

## Options and caveats

- **LG SDP / clock sync (on by default):** webOS gets its clock from LG's SDP
  servers (`*.nextlgsdp.com`). SDP is left open for 60 seconds at boot so that
  the TV can set its clock, then blocked. Because the LG Content Store also
  needs SDP, the store will stop opening once that grace period ends (error
  `-102` or `P6.48.SZ`) — leave this off if you use the store. AirPlay keeps
  working.
- **Clock from NTP (off by default):** Sets the clock from `pool.ntp.org`
  instead, so that SDP can be blocked immediately at boot. Requires outbound
  UDP port 123.
- **Voice services:** Stopping LG's voice services may disable the voice button
  on your remote, and it does not disconnect microphone hardware. If you use an
  on-TV speech app such as
  [Local Voice](https://github.com/haywirephoenix/webos-localvoice), you can
  allow it to keep `voiceinput` running (and `voiceinput_hidraw` on TVs with
  split Magic Remote capture) in the **Exceptions** tab. Note that on tested
  webOS 25 firmware, `voiceinput_hidraw` can start a TLS WebSocket server that
  listens on all IPv4 interfaces, which may expose that service to your local
  network.
- **Local DNS filter (off by default):** Routes ConnMan's IPv4 DNS through a
  local helper using the same blocklist, with a companion toggle to disable
  IPv6. This requires iptables NAT in the TV's kernel; on TVs without it (such
  as the LG B5 on webOS 25), the DNS toggles are hidden automatically. See
  [`dns-filter/README.md`](dns-filter/README.md) for details and limits.
- **Other optional toggles (all off by default):**
  - **ThinQ / companion** — also stops assistant and IoT daemons.
  - **QuickSet** — blocks `www.ueiwsp.com`; leave off if you set up replacement
    remotes.
  - **Home app sessions** (`wiselg`) — blocks session uploads, but also affects
    Home recommendations, previews, and channel metadata.
  - **LG Content Store** (`lgrecommends`) — blocks the store interface and
    recommendation hosts.
  - **Firmware/app updates** — also breaks app installs and updates. You do not
    need this for firmware if you already block updates in the Homebrew
    Channel.
  - **Gallery+** — blocks `*.lggalleryplus.com`, which breaks Gallery+.
  - **UPnP** — disables UPnP discovery both ways, which also breaks casting to
    the TV.

## Uninstall

Uninstalling an app in webOS only deletes its folder, so disable protection
first:

1. Open the app and select **Disable protection**. This unmounts `/etc/hosts`
   and the stubs, restarts the stopped services, rolls back the DNS filter, and
   removes the boot hook.
2. Uninstall the app from the Homebrew Channel.

Your settings and log stay in `/var/lib/webosbrew/` so that a reinstall keeps
them. To remove them as well, run as root:

```sh
rm -rf /var/lib/webosbrew/lifesgoodwithoutspying*
```

<details>
<summary>Already uninstalled without disabling?</summary>

A reboot undoes most of the changes, but two things remain: the broken boot
hook symlink and ConnMan's IPv6 setting (if **Turn off IPv6** was enabled).

- **If you turned off IPv6:** reinstall the app, select **Disable protection**,
  and uninstall it again. Do this before deleting the files in
  `/var/lib/webosbrew/`, because the rollback reads them and the app only shows
  **Disable protection** while the boot hook link exists.
- **Otherwise:** simply remove the dangling link:
  ```sh
  rm -f /var/lib/webosbrew/init.d/50-lifesgoodwithoutspying
  ```

</details>

## Build and manual install

Building requires `ares-package`
([setup](https://www.webosbrew.org/develop/guides/env-setup)), `rsvg-convert`
for icons, and `bun` for the DNS filter bundle:

```sh
./build.sh
```

This writes the `.ipk` and its SHA-256 checksum to `dist/`. With the TV
reachable over SSH, sideload it with `ares-install <device> dist/*.ipk`, or
copy the `.ipk` to `/tmp` on the TV and install as root:

```sh
luna-send -i -f luna://com.webos.appInstallService/dev/install \
  '{"id":"ooo.lew.lifesgoodwithoutspying","ipkUrl":"/tmp/app.ipk","subscribe":true}'
```

Run that over `ssh -tt` (the TV's `luna-send` only prints to a TTY) and wrap it
in `timeout` because `-i` subscribes indefinitely.

## Technical details

<details>
<summary>How service blocking, stand-ins, and background jobs work</summary>

- **Targeted daemons:** Stops `admanager`, `livepick`, `acr2`, `nudge`, `rdxd`,
  `uploadd`, and `sportsalarm`, plus LG voice/NLP services (`voiceinput`,
  `voiceconductor`, `nlpmanager`, `performer`) and the voice app. With ThinQ /
  companion enabled, also stops `trigger_thinq`, `trigger_alexa`, `iot-client`,
  and `iot-proxy`. Optionally stubs `/usr/sbin/upnpd`.
- **Jailed services (webOS 25):** When the Luna hub starts a service inside a
  jail (`Exec=/usr/bin/jailer ...`), the jail gets a fresh `/usr` without the
  mounted stub. For those services, the app bind-mounts a modified `.service`
  file pointing `Exec` to the stub and runs `ls-control scan-services`.
- **Service stand-ins:** Because the Luna hub still lists stubbed services,
  `nospy-luna-stub.js` (requires `node` on the TV) registers `admanager`,
  `voiceconductor`, and `voiceinput` and returns minimal answers (an all-zero
  ad ID and no voice languages) without reading any ID or touching audio. The
  self-test reports whether each stand-in is running.
- **Host-based sink limits:** The self-test's `getent` and `curl` checks only
  verify that `/etc/hosts` is visible to the local resolver. Services that use
  their own DNS path (such as DNS-over-TLS) can bypass `/etc/hosts`, so the
  voice and ad process checks are the stronger signal.
- **Background jobs and CLI:** Enable, Update, and Disable run as background
  jobs with a 240-second timeout. Over SSH, `nospy-ctl.sh job` (or `status`)
  shows `job=running|done|failed|idle` and `nospy-ctl.sh joblog` prints the
  last job's output.

</details>

<details>
<summary>App exceptions (for homebrew developers)</summary>

A homebrew app installed under `/media/developer/apps/usr/palm/applications`
can request permission to keep `voiceinput` and `voiceinput_hidraw` running
(while the rest of the voice group stays stubbed) or to answer for a stubbed
service in place of the built-in stand-in. Every exception starts off until the
user enables it in the **Exceptions** tab. With **Voice** blocking on, enable
and apply Local Voice's `voiceinput` exception (and its `voiceinput_hidraw`
exception on TVs with split Magic Remote capture).

- **Register:** Write `/var/lib/webosbrew/lifesgoodwithoutspying.exceptions.d/<app_id>`
  with one line per request (`keep voiceinput`, `keep voiceinput_hidraw`, or
  `claim <service>`), then run `nospy-ctl.sh apply`.
- **Allow via CLI:** Run
  `nospy-ctl.sh set exception.<app_id>:<keep|claim>:<name> on` followed by
  `nospy-ctl.sh apply`.
- **Unregister:** Remove the file and run `nospy-ctl.sh apply`.
- **Claim a service (once allowed):** Write `<pid> <start time> <app_id>` to
  `/tmp/lifesgoodwithoutspying.claim.<service>` (where `<start time>` is field
  22 of `/proc/<pid>/stat`), then kill the PID in
  `/tmp/lifesgoodwithoutspying.answer.<service>.pid`. The stand-in yields while
  that process runs from the app's folder and resumes once it exits. The real
  LG binary stays stubbed.

On webOS 5.4, `voiceinput` passes audio to a local socket and makes no network
calls of its own. Homebrew runs as root, so this mechanism relies on apps
cooperating.

</details>

<details>
<summary>DNS filter, NTP, and AirPlay internals</summary>

- **DNS filter (`dns.filter`, `dns.disable_ipv6`):** The helper in
  [`dns-filter/`](dns-filter/) reads an atomically replaced domain list derived
  from `/etc/hosts` (excluding `localhost`) and uses iptables NAT to redirect
  port 53. If the kernel lacks `ip_tables` (e.g., LG B5 on webOS 25:
  `can't initialize iptables table 'nat'`), the app refuses `set dns.filter on`
  and turns off any previously saved setting the next time protection is
  applied. There is no
  fallback: pointing ConnMan's nameserver at the helper broke DNS on webOS 6
  and fell back to upstream on the emulator, and pointing `resolv.conf` at it
  would only cover lookups that `/etc/hosts` already handles. On webOS 4.x
  (which lacks `busctl`), the filter reads ConnMan settings with `dbus-send`.
  See [`dns-filter/README.md`](dns-filter/README.md) for CNAME, EDNS/COOKIE,
  and fail-closed details.
- **NTP (`clock.ntp`):** Runs a small Node SNTP client against
  `0-2.pool.ntp.org`, sets the time via
  `com.webos.service.systemservice/time/setSystemTime` with a fallback to
  `date -s` (needed on webOS 9 when network time is on), and retries in the
  background for up to 10 minutes at boot if the network is not up yet.
- **AirPlay MFi check:** AirPlay checks the TV's MFi key through SDP on first
  use after power-on. While SDP blocking is enabled, protection marks that
  check as complete so that AirPlay uses the key already on the TV.

</details>
