# LG Service Delivery Platform (SDX) hosts. Toggle: domains.sdp
#
# When enabled, these hosts are omitted from the sink for the first 60 seconds,
# then blocked. webOS uses an SDP response's X-Server-Time header to set the
# clock during boot; without it the TV can remain at 2023-01-01.
#
# SDP is also used for LG service initialization, device registration and
# authentication, app metadata, and EULA/notice data. The grace period therefore
# permits more than clock synchronization.
#
# AirPlay's first-use MFi key check also goes through SDP; nospy-apply.sh skips
# it while this category is on (mfi_flag_hold), or pairing fails.
